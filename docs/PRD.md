# Matrix Sports

# Product Requirements Document (PRD)

**Versão:** 1.0

**Status:** Em desenvolvimento

**Cliente:** Clube Curitibano

**Projeto iniciado em:** Agosto de 2026

---

# 1. Visão Geral

O Matrix Sports é um sistema web de gestão esportiva desenvolvido para substituir a Matrix em Excel utilizada pelo Clube Curitibano.

O sistema centralizará todas as informações esportivas, administrativas e financeiras em uma única plataforma.

---

# 2. Objetivos

O sistema deverá permitir:

- Gestão completa de atletas.
- Gestão de professores.
- Gestão de turmas.
- Gestão de quadras.
- Controle de presença.
- Agenda de treinamentos.
- Controle de torneios.
- Registro de resultados.
- Rankings.
- Controle de fisioterapia.
- Controle de uniformes.
- Gestão financeira.
- Gestão de projetos CBC.
- Dashboards em tempo real.

---

# 3. Público-Alvo

- Diretores.

# 5. Situação Atual

Atualmente o controle é realizado por meio da Matrix em Excel.

O objetivo do projeto é migrar gradualmente todas as funcionalidades para uma plataforma web moderna.
